CPSC 335 Final Project - START HERE

1. Read Final_Project_Instructions.pdf (all requirements, grading and deadlines).
2. With your partner, choose ONE project folder: GridRestore, ShipSmart or BloodLink.
3. In that folder, open a terminal and run:
       pip install -r requirements.txt
       streamlit run app.py
   (Mac: pip3 / python3. If "streamlit" is not found: python -m streamlit run app.py)
4. Take a screenshot of the app running and submit the "Project Choice & Setup Check"
   assignment on Canvas.
5. Write your code in core.py. Check your progress with:  python check_project.py
